# Spike — the payload experiment: two dispatches review their own brief

Run 2026-08-13/14 against two live dispatches: it-hapc (fire-time liveness — mid-size feature, rich neighborhood) and it-hjed (find match hygiene — small settled bug, thin neighborhood). Protocol: stage one, announced at spawn — a candid payload review written at join, before work; stage two, revealed only after the work report — an honest q-account from the agent's own transcript, then a far-and-wide read of the whole graph, then a second review knowing what the payload omitted and what the work actually consumed. Payload copies were captured by the dispatcher via `q brief` at dispatch-time graph state (41KB and 38KB). The spike node was deliberately not minted until both runs finished, so the exploration could not find its own experiment.

Artifacts in this folder: per-run payload copies, first reviews, q-accounts, second reviews. The work reports live in docs/reports/ as ordinary dispatch reports.

## Finding 1 — agents work payload-only; a complete-feeling brief switches off the graph

Run 1: zero deliberate graph consultation during work ("it did not occur to me to look, because the payload felt complete"). Run 2: exactly one — `q guide` at citation time, and that consultation was *manufactured by the payload itself*: ACTOR RULES mandate citing, nothing states the legal edge matrix. Both agents closed every other gap by reading src/, never the graph. dc-kpqg's "the brief is the floor, not the whole interface" doctrine was invisible to both — neither knew mid-work reads were expected to be free, and near-misses followed directly (run 1 rebuilt the launcher convention from code archaeology while it-3pab — whose body literally names it-hapc as its heir — sat unrendered one q open away). th-3pq2's post-mortem lesson is corroborated from the other side: shelf lines do not transmit norms; placed lines do.

## Finding 2 — payload weight tracks area history, not item need

41KB vs 38KB for items of very different size: the shelf scales with what the area accumulated. Receipts, run 1: 6 of 27 spine claims earned their place; 14 of 15 doc lines went unused — while two of those docs held exactly the code maps the agent's first review wished for (noise by presentation, not content). Run 2: ~5 of ~60 read-first entries earned; 16 doc-report lines, zero opened. Dedup failure alone costs a third (dc-crea rendered twice, dc-ydvb's substance three times, dc-nnf5 twice — in a brief that itself cites th-uacu).

## Finding 3 — the sharpest result: everything missing was already in the graph

Neither run's gaps needed new content invented. The item's own `about: file:` edges (blob-stamped code geography — both runs' top first-review wish) sit in the item's frontmatter, unrendered. The dispatched item's mentioned-by backlinks (derived machinery, already implemented for open/view) would have caught run 1's one true miss. The edge matrix, the claim-species instruction (cl-ybth landed kindless where dc-yd9s expects a species — fixed at harvest), the register corpus for wording calls, dc-wngq for the vacuous-fit judgment — all present, one selection policy away. The agents' shared verdict: nothing needs inventing; th-uacu needs settling.

## Finding 4 — convergent structural proposals (evidence for th-uacu, not settlements)

Independently, both second reviews converged on:

1. **Tier the payload**: CONTRACT (work, acceptance, write-set, return, protocol) → SEMANTICS (read-first bodies, once) → MAP (the item's own file:-edges with blobs; mentioned-by backlinks; landing reports' where-things-live for read-first items; machine state when the item is coordination-flavored) → YOUR-WRITES (the graph acts expected at landing, each with its legal edge shapes and expected claim species) → ranked shelf → counts of the omitted with a reach-them command. Nothing hides silently; the backdrop declares itself backdrop.
2. **Render each node once** — highest tier wins, later occurrences compress to a ref.
3. **Rank the shelf by lexicon overlap** with THE WORK + acceptance names. Validated post-hoc on run 2: the overlap set selects exactly the five entries the work used and excludes the dispatch-machinery corpus. The dc-grrb bodies-on-the-shelf tension resolves as: full bodies for the ranked few, atom lines + count for the rest.
4. **Move the acceptance-empty confrontation to the dispatcher at fire time** — an agent writing its own acceptance is the Goodhart shape dc-grrb warns about (run 1 did exactly this, flagged it itself).
5. **Print dc-kpqg's floor line in every brief** — one sentence recalibrating the agent's relationship to the graph.
6. **Keep verbatim**: PROTOCOL, ACTOR RULES, RETURN's reflections paragraphs, the write-set frame — every line fired at least once in both runs.

## Side findings

- **Read side-effects are unannounced.** q reads advance watermarks and heartbeat the dispatching session (th-xvv6); dc-kpqg rules mid-work reads free. Run 2 ran its verification finds "in innocence" and said so: an agent cannot honor an invariant it has never been told exists. The tension is the user's to settle; the brief is where the answer must eventually ride.
- **Reads are not logged.** The q-accounts rest on transcript and self-report; only writes ground against the log. Fine for this spike; any future measurement wants that stated up front.
- **Method notes.** The q-audit was unannounced until stage two in both runs (the behavior finding is clean); the stage-one review ask does prime payload attention (accepted — payload critique was the point). Asymmetry: run 2's stage-two exploration was instructed to prefer direct file reads; run 1 chose that on its own for the same reason (watermark hygiene). Run 2's agent finished under a branched session; its report was relayed verbatim via the shared scratchpad and harvested normally — graph accounting was unaffected.

## Disposition

This spike is evidence for th-uacu (the brief is a dump: selection, hierarchy, dedup) and touches th-zzqv (bundled work — the payload must grow; these findings say where the headroom is), it-b2sp (dispatcher context burden — the same disease on the other side of the fence), and th-xvv6 (read side-effects). Selection policy remains the user's call.
