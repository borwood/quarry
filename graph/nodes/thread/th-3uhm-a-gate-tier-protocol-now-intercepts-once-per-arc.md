Surfaced building it-nngn, and it is the flip side of that fix rather than an argument against it.

WHAT CHANGED IN COST. dc-pwyd rules that attention rides the actor, and it-csm3 applied it to watermarks and drift deliveries - surfaces whose delivery is an INLINE line printed beside a verbs own output. it-nngn applies the same key to the gate-tier protocol memo, whose delivery is not a line: gate_if_needed refuses the act, exits 2, saves the intent under a one-time token, and demands q resume. Pre-fix the holding session absorbed that interception once and every arc it dispatched rode free. Post-fix each joined agent is intercepted on its own first matching act.

THE SIZE OF IT, on this repo's own numbers: 2026-08-21 alone landed on the order of a dozen dispatched arcs. A project that registers a gate-tier protocol on q new (this repo has do-n47r on doc/journal; the floors work of it-vzx6 and it-qra3 would add more, and dc-yd9s makes per-kind floors protocol content) turns that into a dozen gate-and-resume round trips instead of one, each costing the agent a refused command and a re-run.

WHY IT IS STILL RIGHT AS BUILT, and why this is a question rather than a defect: the whole premise of this machine is that every agent wakes with no memory, so a house rule the project wants OBEYED must reach the mind that is about to act - a memo spent by a session the agent never was is a teach nobody received. That is exactly dc-pwyd's has-this-READER-seen-it, and the dispatch brief is the same move at a larger grain. The pre-fix behaviour was not cheap correctness; it was silence.

THE CALL, if the cost turns out to bite: is a gate the right TIER for a rule a dispatched agent meets, or should protocol content aimed at agents ride the brief (where the teach is already delivered free, at the join, and the arc first mint does not re-gate per cl-b2z2) with the gate tier reserved for the design seat? That fork lives in the protocol layer, which dc-9hgd and dc-yd9s put in the projects hands, not the engines. Nothing is settled here and nothing was built toward it; recorded so the cost is visible before the floors work multiplies the number of gate-tier rules.
