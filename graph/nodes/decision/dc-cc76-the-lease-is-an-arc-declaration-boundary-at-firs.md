Ratified 2026-08-09. The boundary: a lease begins when an item arc starts touching files - whoever the hands; dispatch is the delegated instance of that moment. Solo-leaseless is not a blessed case: the lease is the declaration that feeds spine extraction at landing (spine_check takes the lease globs as the landed-uncited input - see "spine landmarks"), presence to sibling sessions, and scope-creep detection; a leaseless arc exits without the graph learning a capability landed. What stays genuinely leaseless: browsing, design, graph writes, item-less casual edits. Build shape: (1) q dispatch <item> - one act: render the derived brief, reserve, set in-flight, print the hand-off payload (brief + QUARRY_DISPATCH marker); advertised where dispatch decisions happen (ready listings, brief, guide); refuses in an unbound chat and points at session adopt - no provisional leases. (2) The solo path gets the same convenience: q reserve advertised when a session takes up an item and is about to write code. (3) Leaseless code writes are never denied - the guard accrues a machine-local per-session touched-set (O(1) append, no graph load on the write path); crossing a threshold of distinct source files triggers a once-per-session derived nudge naming the item whose write-set or file-edges cover the touched paths (no match: no item covers these, sketch one?); wrap picks up leaseless touched files with the observed set standing in for lease globs (spine prompt + retroactive filing); the observed set feeds soft presence. Denial remains only for foreign exclusive zones and dispatch containment (C7/C8). Goodhart guard: a blocked write breeds junk leases, so prompts not gates. Needs testing when built.
