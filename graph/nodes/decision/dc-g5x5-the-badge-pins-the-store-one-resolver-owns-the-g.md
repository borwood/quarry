Settled 2026-08-18, closing the diagnosis recorded on this thread: Shape A - the badge pins the store. Dispatch mints the canonical graph root into the spawn line beside the join token; every verb and hook acting under that badge resolves its store from the pin, never from cwd walk-up. Blob stamps hash the file the agent actually touched - worktree content, the right content - against the store-relative path; the worktree's own graph/ copy stays inert at its fork state and merges clean because nothing on the branch side writes it. Rejected: fork-and-reconcile (id collisions, version drift, a merge machine to reconcile a fork the pin prevents) and graph-less worktrees (stands on worktree geography and per-checkout configuration - discipline, not construction). The user's anticipation constraint, load-bearing for the build: ONE source of truth for the graph locale - a single resolver through which every verb and hook obtains the store, precedence pin -> (future: configured location) -> cwd discovery fallback - swappable in place, so a gitignored graph or a fully out-of-repo graph changes only the resolver. No call site bypasses it (the dc-nnf5 lint pattern). Identity symmetry: the pin travels the injection channel beside QUARRY_SESSION and QUARRY_ACTOR, launcher env wins - one bundle carrying who acts, which session holds, and where acts land.
