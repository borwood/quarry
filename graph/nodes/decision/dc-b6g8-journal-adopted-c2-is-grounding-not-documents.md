The journal is adopted, decoupled from C2: doc nodes kind=journal at journal/<date>-<slug>.md, written journal-on-story (never on schedule), rendering in-app, citable as a source after the fact — narrative memory and blog feedstock, with voice, flags, and lens taxonomies left to project protocol. C2 is revised from documents to GROUNDING: a claim must carry a source doc, a source file (matrix widened, blob-stamped), a method, or user provenance. The guard is against free-floating assistant assertions, not in favor of paperwork; the main session never stops mid-thread to manufacture a source.
