Tags in three registers, three answers (settled 2026-08-09). As an array field: already possible — the project field registry preserves unknown fields verbatim, never interpreted; zero engine work, and per the schema-capped principle the engine interprets nothing new until a real query hurts. As an authority: rejected — areas already are the controlled tag vocabulary (defined, versioned, reviewable); free tags would be a shadow taxonomy riding a remembered convention, the kind measured to die (JUSTIFIED-BY: documented twice, used three times). A tag that proves load-bearing is an area wanting to be born. As matcher fuel: unnecessary — tags would add recall only for pre-nodal concepts, and the reverse match at nodehood closes that gap convention-free. Hashtags in bodies rejected: bodies are title-first prose by ruling; backticks already mark concepts.
