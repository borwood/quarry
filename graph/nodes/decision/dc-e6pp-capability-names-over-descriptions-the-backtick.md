User-ruled 2026-08-09. Named building blocks reason better than nameless blobs — the same logic as the suite register (`augury`, `core-sample`). Vein claims title name-first: `name`: what it provides. A named vein can be reviewed, amended, superseded, reconsidered — and every build that cited it surfaces by blast; a description can only be paraphrased. The backtick meme is instilled by USE in tool surfaces, never by instruction: agents mirror the style they read. It is also mechanically load-bearing — backticked spans boost the relatedness match, so the meme and the attention layer reinforce each other. USER ADDENDUM (2026-08-09): the philosophy itself can be instilled through deep references at the surface — `systematic nomenclature`, `intention-revealing names` — one-phrase anchors that invoke entire trained bodies of practice, the same class as naming Goodhart.
