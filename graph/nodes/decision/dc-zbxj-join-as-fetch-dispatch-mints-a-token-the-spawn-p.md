Ruled 2026-08-13 by the user, hashed out in conversation on th-6upm (first topic of the findings triage). The hand-off is a FETCH, not a paste: q dispatch mints a single-use join token into its output; the spawn prompt collapses to one line (run q join <token> and follow what it prints); q join binds the acting agent identity to the badge and renders the brief fresh from the graph at read time - the brief doctrine (derived, never hand-carried) applied to the hand-off itself, so a stale or dispatcher-mangled copy is impossible and bulk dispatch is N one-line prompts. Anything the dispatcher would have added around the payload belongs in the graph - written to the dispatched item if that is where it belongs - so the derived brief carries it.

Identity is structural, never discipline: hooks do IDENTITY INJECTION ONLY (QUARRY_AGENT rides the session hook alongside CHAT/SESSION/ACTOR; the harness provides agent_id to hooks run in a subagent - probed 2026-08-13: subagent shells are otherwise indistinguishable from the parent chat in both hook session_id and environment). q resolves badges from the association map; per-shell export dies; QUARRY_DISPATCH env survives only as the out-of-hook-coverage override.

The join gate makes the instruction construction: file writes into a dispatched lease's globs from a context resolving no badge are DENIED with the teaching line (this zone belongs to a dispatch - q join first), the C8 move applied to the hand-off. The pre-join gap is safe by inventory: leased-zone writes deny and teach; outside writes are ordinary leaseless observation (sub-threshold dispatcher chores per dc-cc76 need no item and no stamp); q acts stamp nothing - no-attribution over mis-attribution.

Stamping follows the WORK, never the holding chat: held entries resolve refusal and boundary only; the dispatcher's unrelated mid-flight acts never stamp into a dispatch trace (the defect th-6upm opened with). Dispatcher-side registration of spawned agent ids was considered and rejected - discipline-shaped and gap-shaped; the payload token is the only vector that is per-agent, bulk-safe, and constructed. Deferred to their own discussion, deliberately unruled here: multi-badge held state and the double-dispatch refusal (hole 5).
