THE BADGE: QUARRY_DISPATCH carries the item id; every verb the agent runs stamps it; guard containment unchanged. CHOKE POINTS: (1) the write hook, the guaranteed in-flight channel: first interception under a badge echoes the contract (item, globs, RETURN spec); badge-keyed drift notice when cited nodes move mid-flight - rides accrual state, never a per-write log scan. Harness done is a STOP SIGNAL, never a quarry transition (deepcraft prior: agents report done while polling the build mutex) - the item stays in-flight and the lease held until landed. Harvest mechanically compares observed vs expected (files touched, claims minted under badge, threads filed vs report language) and prints the mining homework. Quarry clerks; the dispatcher judges.

THE REPORT: registered as a doc at harvest - the harness guarantees final prose exists; registration is one homework command; the dispatcher judges whether a given report earns it (prompt, never gate). Agent-authored, actor-attributed, badge-stamped. The RETURN spec grows a reflections section: outcomes first, then doubts, observations, suggestions in the agent own words; a stop-before-acceptance report says why and where it stopped - partial reports register too, and re-dispatch re-renders a brief that now carries prior reports (resumable dispatch falls out). Prose stays prose; mining is extraction-on-citation: doubts become threads, observations become debt items or claims with the report as source.
