Four teaching surfaces, one authority each: --help owns all syntax (generated from the arg parser, cannot drift); error messages own the constraints, teaching at violation time with the corrective verb named; one small generated skill owns judgment and never states a flag; the graph itself owns current state via queries. The binary distributes the teaching: q init --claude writes the skill and the C6 guard hook from templates embedded at compile time, and q guide prints the same primer, so tool version and teaching version travel together.
