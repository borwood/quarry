Builds dc-g5x5, the store-pin ruling that resolved th-xeqw. One seam, three faces. (1) The resolver: a single function owns graph-locale resolution for every verb and hook, precedence pin -> cwd discovery fallback, with the future configured-location slot living between them - swapping locale logic touches only this function. Store::discover becomes the fallback arm; no other call site resolves a store (hold the floor the dc-nnf5 way: lint). (2) The pin itself: dispatch stamps the canonical graph root into the spawn line beside the join token, and the pin rides the identity injection channel (dc-zbxj; cl-z6gc's bundle) with launcher env winning - every badged shell carries who acts, which session holds, and where acts land. (3) The proof: a worktree dispatch exercising the chain end to end - join, badged mints, hook-observed writes, harvest - all landing in the canonical store while cwd sits in the fork. Blob stamps hash the touched worktree file against the store-relative path. The worktree's own graph/ copy is never written.
