Named as residue from the agent seat at the it-d4bh landing, 2026-08-21, with render.rs inside that arc's lease — left unbuilt because a land-time ask is a second mechanism with its own framing and its own ratification, not a second call to the mint prompt.

THE ASYMMETRY. Two shapes can reach ratification wrong, and only one has a backstop. A KINDLESS backtick-titled claim is caught twice: cl-sv7z asks the species question at every mint surface, and cl-vuda lists it again at harvest with the settle command, so an author who ignored the first question meets it before a judge ratifies. A vein or feature carrying NO backticked register name is now caught once — cl-2dhg asks at the mint and nothing asks again. Dismiss that prompt and the claim ratifies nameless.

WHY THAT MATTERS MORE HERE THAN FOR THE KINDLESS SHAPE. A kindless mint is usually a choice the author knows they are making. A nameless one frequently is not: it-d4bh measured that this shell silently eats both backticks off any register name whose first letter is not an escape letter, so the author may have typed the name correctly and never learn otherwise. The mint prompt is the only signal, it fires once, and it fires at the moment the author is least likely to reread their own title. A name that never lands stays invisible to the backticked join dc-qvtz rules on — the vein is inert to relatedness and intent-delta while reading perfectly well to a human.

THE SHAPE, following cl-vuda exactly. Harvest already enumerates badge mints and asks about the kindless ones; the same enumeration can ask about register-species mints carrying no backticked name, with the retitle settle command in hand — cl-h9d6 made a retitle carry its file, so the repair is now complete rather than cosmetic. Prompt and never a gate (dc-grrb), and the framing must say out loud that a deliberately plain title is a fine answer: this check cannot distinguish an eaten name from an intended one, and a prompt that implies otherwise manufactures the fool's-gold naming the brief warns against. That sentence is the whole design risk.
