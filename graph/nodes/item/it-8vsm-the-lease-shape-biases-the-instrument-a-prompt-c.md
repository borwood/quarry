Surfaced from the agent seat at the it-8k3p landing, 2026-08-21, as a reflection rather than a finding, and lifted here because it shapes what gets built rather than any one build.

Composed prose splits by species and the split has a cost the design never priced. A ratified PROMPT string lives in src/framings.rs; an inline REFUSAL string lives wherever it fires. So an arc whose lease covers the code it repairs can always afford a refusal, and can only afford a prompt if the dispatcher happened to lease framings.rs too. The instrument an agent reaches for is therefore chosen partly by the write-set it was handed, not only by which instrument is right.

MEASURED IN THIS ARC. it-8k3p landed a refusal on malformed written form, which was correct. The same arc could not build the prompt its residue wanted — a name whose first letter is not a PowerShell escape letter loses its backticks and nothing else, arriving as a legal plain title nothing can detect, which wants a nudge at the vein mint rather than a refusal at all. That string belongs in framings.rs, which sat outside the lease, so the residue was filed as it-d4bh instead of built. The dispatcher who wrote that lease (this seat) never considered framings.rs, because nothing in the fire suggests it.

WHY IT MATTERS BEYOND ONE ARC. dc-grrb rules that vein landmarks are presence prompts, never gates — the house has a standing preference for prompting over gating in a whole class of surfaces. A structural bias toward refusals therefore pushes against a user ruling, quietly, one lease at a time. Nobody chose that; it falls out of where the two kinds of string happen to live.

SECOND INSTANCE, AND IT GENERALISES THE ITEM. it-d4bh was then dispatched WITH framings.rs leased — the discipline below, applied — and the prompt built cleanly. But that arc hit the same wall one file over: its new check and cl-sv7z's existing one now both carry the same register-species test inline, and the shared predicate that should hold it belongs in queries.rs, which was outside the lease. So it was left duplicated and named in the report.

That is the same shape without the framings split anywhere in it. The bias is not really prompts-versus-refusals; it is that a lease drawn around the code a repair TOUCHES excludes the code that repair should FACTOR INTO, and factoring is exactly the move that keeps a predicate a single point. Every arc under a tight lease is quietly pushed toward inline duplication, which is the opposite of the vein doctrine the briefs preach at the same agents. Two instances in two consecutive arcs, neither foreseeable at the fire.

THE CHEAP HALF IS DISPATCHER DISCIPLINE and costs nothing: lease framings.rs on any arc whose repair might plausibly want a prompt, and lease queries.rs on any arc that might want a shared predicate. This seat adopted the first at it-d4bh and is adopting the second now. But discipline is the road this system rejects elsewhere, and a dispatcher cannot always foresee which repairs will want which — the it-8k3p fire could not have, and the it-d4bh fire did not.

THE REAL FORK IS THE USER'S, because it touches the ratified register: whether the framings/inline split should track SPECIES (prompt vs refusal) at all, or whether it should track RATIFICATION (user-ratified prose in framings, arc-composed prose inline, whichever kind it is). The second reading would put a new prompt inline on the dc-vzvf flag channel like any other composed string, and move it to framings only once the user ratifies it — which is what the flag channel already does for every other composed string. That would remove the framings half of the bias without loosening the pen. The factoring half is a different question and may want nothing more than a habit at the firing station.

Filed as an observation, not a proposal: this seat holds no design pen, and the split is dc-vzvf's ground.

Neighbourhood: it-8k3p for the arc that measured it, it-d4bh for the prompt it could not build and the duplication it then could not factor, dc-vzvf for the register the fork touches, dc-grrb for the standing preference it pushes against.
